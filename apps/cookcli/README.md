# CookCLI

<img src="https://cdn.jsdelivr.net/gh/selfhst/icons/svg/cookcli.svg" width="64" height="64" alt="">

**[🇧🇷 Leia em português](./README.pt-BR.md)**

Plain-text recipes in the CookLang format — versionable in git, with no database and no forms.

## First run

Open `http://<host-ip>:9080` or `https://cookcli.<your-tailnet>.ts.net`.

## Files

```
cookcli.container
aisle.conf.example
bolo-de-cenoura.cook.example
calda-de-chocolate.cook.example
pantry.conf.example
semana.menu.example
install.ini
```

## Remove

The tailnet node is not deregistered when an app is removed: do that in the Tailscale admin.
