# CookCLI

<img src="https://cdn.jsdelivr.net/gh/selfhst/icons/svg/cookcli.svg" width="64" height="64" alt="">

**[🇺🇸 Read in English](./README.md)**

Receitas em texto puro no formato CookLang — versionáveis em git, sem banco e sem formulário.

## Primeiro acesso

Abrir `http://<ip-do-host>:9080` ou `https://cookcli.<your-tailnet>.ts.net`.

## Arquivos

```
cookcli.container
aisle.conf.example
bolo-de-cenoura.cook.example
calda-de-chocolate.cook.example
pantry.conf.example
semana.menu.example
install.ini
```

## Remover

O nó da tailnet não é desregistrado ao remover um app: isso é no admin do Tailscale.
