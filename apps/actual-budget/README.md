# Actual Budget

Fast, privacy-focused personal finance management using the envelope budgeting method.

## First run

Open `http://<host-ip>:5006` or `https://actual.<your-tailnet>.ts.net`.

## Files

```
actual.container
.env.example
install.ini
```

## Remove

The tailnet node is not deregistered when an app is removed: do that in the Tailscale admin.
