Servidor de arquivos estáticos.

## Primeiro acesso

Abrir `http://<ip-do-host>:8103` ou `https://nginx.<your-tailnet>.ts.net`.

## Arquivos

```
nginx.container
install.ini
```

## Remover

O nó da tailnet não é desregistrado ao remover um app: isso é no admin do Tailscale.
