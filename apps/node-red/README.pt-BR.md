Automação de fluxos via editor visual de nós.

## Primeiro acesso

Abrir `http://<ip-do-host>:1880` ou `https://node-red.<your-tailnet>.ts.net`.

## Arquivos

```
node-red.container
.env.example
install.ini
```

## Remover

O nó da tailnet não é desregistrado ao remover um app: isso é no admin do Tailscale.
