Flow automation through a visual node editor.

## First run

Open `http://<host-ip>:1880` or `https://node-red.<your-tailnet>.ts.net`.

## Files

```
node-red.container
.env.example
install.ini
```

## Remove

The tailnet node is not deregistered when an app is removed: do that in the Tailscale admin.
