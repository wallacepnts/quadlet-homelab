Workout planning and tracking, with an exercise database and body measurements.

## First run

Open `http://<host-ip>:8102` or `https://wger.<your-tailnet>.ts.net`.

## Files

```
wger.container
.env.example
install.ini
```

## Remove

The tailnet node is not deregistered when an app is removed: do that in the Tailscale admin.
