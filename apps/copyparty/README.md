# Copyparty — Podman Quadlet (rootless)

**[🇧🇷 Leia em português](./README.pt-BR.md)**

Deploy do [Copyparty](https://github.com/9001/copyparty) (servidor de
arquivos com upload pelo navegador) via Podman Quadlet, usando a imagem
oficial `ghcr.io/9001/copyparty-ac`.

Upload straight from the browser or the phone, with resumable transfers,
thumbnails and search, plus WebDAV, FTP and SMB in the same process. It fills
the gap [ownCloud](../owncloud/) (sync) and [Syncthing](../syncthing/)
(replication) leave: "send that file here now, from any device".

## Architecture

A single container, Python, with **no database** — the index lives in a
SQLite file generated by itself inside the served volume. It takes this
repository's strongest hardening level (`ReadOnly=true`,
`DropCapability=ALL`, `User=1000`),
testado exercitando o app.

Dois volumes: `/cfg` (o `copyparty.conf`) e `/w` (a raiz servida).

### A 256M Tmpfs, not 64M

Chunked uploads pass through `/tmp` before becoming the final file. This
repository's default 64M overflows on a large file — the same logic as
`karakeep-chrome` and vaultzap
([conventions, rule 20](../../docs/conventions.md)).

### Variante da imagem

Upstream publishes three: `copyparty-min` (the basics only), `copyparty-im`
(image and audio) and `copyparty-ac` (**the one used here**: thumbnails,
metadata search and media conversion). Switching to `min` saves about 100 MB
if you do not need thumbnails.

## Security

**The config stores the passwords in clear text**, which is why it lives in
the volume and is not versioned — the repository ships only the `.example`
with the field marked for replacement.

The `.example` already sets access to **closed**: without an account, nothing
is listed and nothing is downloaded. Verified in practice — an anonymous
request for a file returns `403` and the index does not show the file's name.
The root `/` answers `200` because it serves the login screen; that is not
access.

To open a folder to a visitor (the "upload to me without an account" case),
Copyparty has per-path `accs` — see the
[accounts and volumes documentation](https://github.com/9001/copyparty#accounts-and-volumes).

## Installation

```bash
python3 install.py copyparty            # dry-run: shows what it will do
python3 install.py copyparty --apply
```

For the local network only, `--access local`; on the tailnet and the LAN,
`--access both`. Adding `--href-local` points the dashboard link at the LAN.
The script creates the directories, writes the `.env`, generates the secrets,
fixes the volumes' ownership, starts the service and prints the address at the
end — see [Installing and operating](../../docs/installing.md).

Open `http://<host-ip>:3923` (ou via [tsdproxy](../tsdproxy/) em
`https://copyparty.<your-tailnet>.ts.net`).

<details>
<summary><b>Manual installation</b> (advanced) — the same steps, one at a time</summary>


```bash
# 1. Download the unit (no need to clone the repository)
mkdir -p ~/.config/containers/systemd
wget -P ~/.config/containers/systemd/ \
  https://raw.githubusercontent.com/wallacepnts/quadlet-homelab/main/apps/copyparty/copyparty.container

# 2. Directories
mkdir -p ~/.config/containers/volumes/copyparty/{cfg,data}

# 3. Config — TROCAR a senha antes de subir
wget -O ~/.config/containers/volumes/copyparty/cfg/copyparty.conf \
  https://raw.githubusercontent.com/wallacepnts/quadlet-homelab/main/apps/copyparty/copyparty.conf.example
${EDITOR:-vi} ~/.config/containers/volumes/copyparty/cfg/copyparty.conf

# 4. Dono correspondente ao User=1000 da unit
podman unshare chown -R 1000:1000 ~/.config/containers/volumes/copyparty

# 5. Start it
systemctl --user daemon-reload
systemctl --user start copyparty
```

Open `http://<host-ip>:3923` (ou via [tsdproxy](../tsdproxy/) em
`https://copyparty.<your-tailnet>.ts.net`).

## WebDAV

The same address serves WebDAV, with no extra configuration — it can be
mounted as a network drive on the phone or in the desktop's file manager,
using the same account from `copyparty.conf`.

## Auto-update

No `AutoUpdate=` — an explicit tag (`1.20.20`), bumped by hand
(rule 9 of the [conventions](../../docs/conventions.md)). The files it serves are yours; review by hand before changing version.

## Backup & recovery

```bash
systemctl --user stop copyparty
tar -czf copyparty-backup-$(date +%Y%m%d-%H%M%S).tar.gz \
  -C ~/.config/containers/volumes copyparty
systemctl --user start copyparty
```

`data/` is the files; `cfg/` is the accounts. The index rebuilds itself.

## Useful commands

```bash
systemctl --user status copyparty
podman logs -f copyparty
# check that anonymous access is blocked (should give 403)
curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:3923/some-file
```
