# mdrop

<img src="https://cdn.simpleicons.org/markdown/888888" width="64" height="64" alt="">

**[🇧🇷 Leia em português](./README.pt-BR.md)**

Converts PDF, Office, image and audio to Markdown over the web, stateless and without leaving the machine.

## First run

Open `http://<host-ip>:8292` or `https://mdrop.<your-tailnet>.ts.net`.

## Files

```
mdrop.container
```

## Remove

The tailnet node is not deregistered when an app is removed: do that in the Tailscale admin.
