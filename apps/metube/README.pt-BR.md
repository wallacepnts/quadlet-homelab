Interface web do yt-dlp — cola a URL e o vídeo cai no disco.

## Primeiro acesso

Abrir `http://<ip-do-host>:8100` ou `https://metube.<your-tailnet>.ts.net`.

## Arquivos

```
metube.container
```

## Remover

O nó da tailnet não é desregistrado ao remover um app: isso é no admin do Tailscale.
