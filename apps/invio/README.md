# Invio

<img src="https://cdn.jsdelivr.net/gh/selfhst/icons/svg/invio.svg" width="64" height="64" alt="">

**[🇧🇷 Leia em português](./README.pt-BR.md)**

Self-hosted invoicing and invoice tracking, on SQLite and with no external service.

## First run

Open `http://<host-ip>:8106` or `https://invio.<your-tailnet>.ts.net`.

## Files

```
invio.container
.env.example
install.ini
```

## Remove

The tailnet node is not deregistered when an app is removed: do that in the Tailscale admin.
