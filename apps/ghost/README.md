A self-hosted blog/newsletter.

## First run

Open `http://<host-ip>:2368` or `https://ghost.<your-tailnet>.ts.net`.

## Files

```
ghost.container
.env.example
install.ini
```

## Remove

The tailnet node is not deregistered when an app is removed: do that in the Tailscale admin.
