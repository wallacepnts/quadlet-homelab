Blog/newsletter self-hosted.

## Primeiro acesso

Abrir `http://<ip-do-host>:2368` ou `https://ghost.<your-tailnet>.ts.net`.

## Arquivos

```
ghost.container
.env.example
install.ini
```

## Remover

O nó da tailnet não é desregistrado ao remover um app: isso é no admin do Tailscale.
