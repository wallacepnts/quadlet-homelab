## Primeiro acesso

Abrir `http://<ip-do-host>:5678` ou `https://n8n.<your-tailnet>.ts.net`.

## Arquivos

```
n8n.container
.env.example
install.ini
```

## Remover

O nó da tailnet não é desregistrado ao remover um app: isso é no admin do Tailscale.
