Workflow automation through a visual node editor.

## First run

Open `http://<host-ip>:5678` or `https://n8n.<your-tailnet>.ts.net`.

## Files

```
n8n.container
.env.example
install.ini
```

## Remove

The tailnet node is not deregistered when an app is removed: do that in the Tailscale admin.
