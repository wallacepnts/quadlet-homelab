# Traccar

**[🇧🇷 Leia em português](./README.pt-BR.md)**

GPS tracking — live map, history, geofences and reports, with a phone app.

## First run

Open `http://<host-ip>:5056` or `https://traccar.<your-tailnet>.ts.net`.

## Files

```
traccar.container
traccar.xml.example
```

## Remove

The tailnet node is not deregistered when an app is removed: do that in the Tailscale admin.
